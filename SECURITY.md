# Security Policy

## Reporting Security Issues

UB Society takes the security of educational smart contracts, software implementations, and infrastructure seriously.
If you discover a potential security vulnerability, please report it responsibly rather than opening a public issue.

## Supported Scope

The following areas are in scope for security evaluations:

- Smart contract templates and code samples in educational tracks.
- Web portal configuration and deployment pipelines.
- Content integrity and cryptographic protocol examples.

## How to Report

To report a vulnerability or insecure implementation, please reach out through one of the following private channels:

- Email: rafif@rafifmsn.com
- Contact society maintainers directly via private message on Discord or Telegram.

Please include:

- A clear description of the vulnerability.
- Steps to reproduce or proof of concept.
- Potential impact and affected modules.
- Any suggested remediation or patch.

## Response Process

Maintainers will acknowledge receipt of reports within 48 hours.
We will coordinate verification, assess the severity, and deploy fixes before public disclosure.
Contributors who discover and responsibly disclose vulnerabilities will be acknowledged with their permission.
