# Agent Instructions

This project contains the educational curriculum, technical modules, and syllabus documentation for the United Blockchain Society.

All AI agents, automated contributors, and editors working in this repository must adhere to the operational workflows defined below.

## Editorial Style and Voice

All generated and revised copy must strictly follow the editorial standards, banned patterns, and persona rules defined in `./VOICE.md`.

Before generating, editing, or reformatting any content in this codebase, load and apply `./VOICE.md`. Key priorities include:

- Strict prohibition of em dashes and en dashes (`—`, `–`).
- Elimination of AI fluff, transitional boilerplate, and filler phrases.
- Direct, technical starts without meta-announcements or labeled conclusions.
- Low-friction, natural phrasing using short, clear sentences.
