# Slide Deck References

This directory houses the original visual PDF reference slide decks for the Fundamentals of Distributed Trust track.

## Purpose and Status

These PDF documents serve as the historical design and structural reference material for the United Blockchain Society curriculum.
The authoritative, production-ready source of truth for all educational delivery is located in the Markdown slide decks under `ppt/fundamentals/`.
Presenters and curriculum contributors should always consult the Markdown decks in `ppt/fundamentals/` rather than these static references.

## Content Customization and Disclaimer

The production Markdown slide decks in `ppt/fundamentals/` expand and improve upon the initial designs:

- Module 01 (parts 1 through 3) features customized, deepened content that does not correspond 1:1 with the early PDF outlines.
- Earlier monolithic drafts, such as unpartitioned course overview slides, have been deprecated and removed.
- All presentation decks in `ppt/fundamentals/` include complete presenter cheatsheets (`Catatan Presenter`), full Indonesian voiceover scripts (`Naskah Tutur`), and English slide layouts.
- Technical explanations, KaTeX equations, and sequence flows in the Markdown decks supersede legacy slide drafts.
